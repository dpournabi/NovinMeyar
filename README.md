# NovinMeyar

I developed an enterprise project for a local company in Hamadan province. The main activity of the company is inspection and issuance of standard certificates for elevators, products and etc. I decided to implement this project on the microservices architect. First of all, I created an IdentityServer microservice. In fact, there are five microservices for this project that we are developing til to complete daily.
```
1-  IdentityServer Service
2-  Technical Service
3-  FileManagment Service
4-  Finance Service
5-  Cartabl Service
6-  Messaging Service

WebSite: http://www.nmaa.co.ir/
```
# Technical Information:
      Backend: C#,NetCore 5.0
      Database: MS SqlServer
      Frontend: Angular 2+
      ServiceBus: RabbitMQ
